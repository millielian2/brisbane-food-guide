# BRISBANE / FOOD — School Project Website

## How to open it
Double-click `index.html`. It should open in your browser.

## How to customise it
You do NOT need to ask ChatGPT every time you want to change something.

### Change restaurant information
Open `script.js` in a text editor. Near the top you will see the restaurant list.
You can change:
- name
- type/cuisine
- address
- price
- description
- image filenames

### Change photos
Put your new photos inside the `images` folder and change the filename in `script.js`.

### Change colours/fonts/layout
Open `styles.css`.
The easiest colours to change are at the very top under `:root`.

### Change the Brisbane introduction
Open `index.html` and edit the text inside the `section` with `id="story"`.

## Google Maps
The address link is automatically turned into a Google Maps search link by `script.js`.
You only need to change the address text.

## Important
This is a static website, so it can be hosted on GitHub Pages, Netlify, Vercel, or similar static hosting later.
